지하철벨 개인정보처리방침

시행일: 2026년 8월 7일

지하철벨(이하 "앱")은 이용자의 개인정보를 소중히 다룹니다.

이 방침은 앱이 무엇을 수집하고 무엇을 수집하지 않는지를 밝힙니다.

1. 요약

항목내용
회원가입없습니다. 계정을 만들지 않습니다
위치 권한「앱 사용 중에만 허용」 — '항상 허용'을 요구하지 않습니다
위치 정보단말 밖으로 나가지 않습니다
광고·분석 도구사용하지 않습니다

서버에 남는 것접속 IP·시각·조회한 노선 번호 (접속 기록)

2. 위치 정보

2.1 왜 필요한가

앱은 이용자가 목적지 두 정거장 전에 도달했는지 판단하기 위해 위치 정보를 사용합니다.

2.1.1 「항상 허용」을 요구하지 않습니다

앱이 요청하는 것은 「앱 사용 중에만 허용」 입니다.

추적은 이용자가 앱에서 루틴을 눌러 시작할 때만 켜지고, 그때부터 알림 표시줄에 추적 중임을 알리는 알림이 계속 떠 있습니다. 이 알림이 떠 있는 동안에는 화면을 꺼도, 다른 앱을 써도 위치를 받을 수 있습니다.

  • 이용자가 시작하지 않으면 앱은 위치를 받지 않습니다
  • 추적을 끄면 즉시 중단됩니다. 알림이 사라진 것으로 확인하실 수 있습니다
  • 앱이 몰래 위치를 받는 경로는 없습니다 — 부팅 시 자동 실행도 하지 않습니다

2.2 어떻게 처리하는가

위치 정보는 이용자의 단말 안에서만 처리되며, 외부로 전송되지 않습니다.

  • 현재 위치와 지하철역 좌표를 단말에서 비교해 가장 가까운 역을 판단합니다
  • 좌표·주소·이동 경로를 서버로 보내지 않습니다
  • 저장하지 않으며, 앱을 종료하면 남지 않습니다

2.3 권한을 거부하면

알람 정확도가 떨어지지만 앱은 동작합니다. 권한은 단말 설정에서 언제든 철회할 수 있습니다.

3. 단말에 저장되는 정보

이용자가 등록한 루틴(승차역·하차역·환승역·이름)이 단말 내부 저장소에 보관됩니다.

  • 서버로 전송되지 않습니다
  • 앱을 삭제하면 함께 삭제됩니다
  • 앱 안에서 개별 삭제할 수 있습니다

4. 중계 서버 통신

앱은 실시간 열차 위치를 얻기 위해 운영자의 중계 서버에 접속합니다.

4.1 앱이 보내는 것

노선 번호 하나뿐입니다. (예: 1007 = 7호선)

역·좌표·목적지·이용자 식별자를 보내지 않습니다.

따라서 서버는 이용자가 어느 역에 있는지, 어디로 가는지 알 수 없습니다.

4.2 서버에 남는 것 (접속 기록)

일반적인 웹 서버와 같이 다음이 자동 기록됩니다.

항목예
접속 IP 주소203.0.113.10
접속 시각2026-08-07 08:12:33
조회한 노선 번호/v1/line/1007
단말 종류(User-Agent)Android 16; SM-S921N
  • 목적: 장애 대응과 비정상적인 대량 호출 차단
  • 보관 기간: 30일 (Google Cloud Logging _Default 버킷 보관 정책, 이후 자동 삭제)
  • 이 기록만으로는 특정 개인을 식별하지 않으며, 다른 정보와 결합하지 않습니다
이용자가 어느 노선을 조회했는지는 기록에 남습니다. 다만 **어느 역에서 타고
어디서 내리는지는 서버가 알 수 없습니다.**

4.3 서버 위치

중계 서버는 Google Cloud Platform(대한민국 서울 리전) 에서 운영됩니다.

서버가 조회하는 실시간 열차 정보의 출처는 서울특별시 열린데이터광장입니다.

5. 수집하지 않는 정보

다음은 일절 수집하지 않습니다.

  • 이름·전화번호·이메일 등 신원 정보
  • 연락처·사진·통화기록·문자
  • 광고 식별자(AAID), 분석용 식별자
  • 이용자의 좌표·이동 경로

앱에는 광고 SDK와 분석 SDK가 포함되어 있지 않습니다.

6. 제3자 제공 및 위탁

개인정보를 제3자에게 제공하지 않습니다.

서버 운영을 위해 Google Cloud Platform을 이용하며, 이는 정보통신 설비의

임차에 해당합니다. Google은 접속 기록을 저장하는 인프라를 제공할 뿐,

별도의 목적으로 이용하지 않습니다.

7. 이용자의 권리

원하는 것방법
위치 정보 제공 중단단말 설정 → 앱 → 권한 → 위치
루틴 삭제앱 안에서 개별 삭제, 또는 앱 삭제
접속 기록 삭제 요청아래 연락처로 요청 (IP·시각 명시 필요)

8. 아동의 개인정보

만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로

수집하지 않습니다.

9. 안전성 확보 조치

  • 앱과 서버 간 통신은 HTTPS로 암호화됩니다
  • 서버의 인증 정보는 별도의 비밀 관리 시스템에 보관하며 앱에 포함하지 않습니다
  • 접속 기록은 최소 항목만 남기고 30일 후 삭제합니다

10. 방침 변경

내용이 변경되면 앱 내 공지 또는 이 페이지를 통해 시행 7일 전에 알립니다.

이용자에게 불리한 변경은 30일 전에 알립니다.
